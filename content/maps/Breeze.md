# Breeze (ブリーズ)

## 概要

開けた砂漠地帯と海辺を舞台とした、**攻撃側が圧倒的に有利**な大型マップです。チョークポイントが多く、防衛側は全エリアを守ることがほぼ不可能であるため、**ギャンブルスタック＋リテイク**を基本配置とします。

### マップの特性
- 攻撃側の進行を止めるのが極めて困難
- ダブルカーテンを利用した2段階エントリー＋フェイクアクションのセットが特に強力
- [[Viper]] など遠隔でスキルを放てるエージェントが重要な役割を担う
- 中盤でMIDを取り返し、囲い込んでリテイクする動きが有効

---

## エリア評価と戦術

### Aメイン
- **構造的特徴**: 覗く速度は攻守変わらず対等。時間が経つと**防衛側に有利なアングル**が増える。詰め切りは攻撃側有利。
- **オーブコントロール**: 攻撃側が確保しやすい。
- **攻撃側のテイク手段**: スモーク＋リコン、ドローン、フラッシュ＋アップドラフト、ドライ進行のいずれも有効。
- **防衛側の動き**: [[Viper]]・[[Sova]]・[[KAYO]] などの遠隔スキル持ちがスキルを返すことで対抗。

### MID（ミッド）
- **構造的特徴**: 防衛側は覗き切るのが困難。スモークやリコン等でリピークも困難で、守りにくいエリア。
- **攻撃側の崩し**: フラッシュ＋ピークなど、スキルと合わせた強引な突破が基本。
- **防衛側の対策**: ドローンを入れた取り返しや、[[KAYO]] のナイフを活用してスキルを起点にした制圧が有効。
- **スプリット起点**: Aスプリットの際にDD（ダブルドア）のチョークポイントで守れると理想的。

### エルボー
- **構造的特徴**: アングルは**防衛側有利**。ダブルピーク、フラッシュ、[[KAYO]] のナイフ等で攻撃側がテイクする手段がある。
- **テイクのメリット**: ここを取れると MID からのローテーションをカットできる。さらにトンネルスモークでトップ抜けのプレッシャーを作れる。
- **重要点**: 取り返しが難しいため、攻撃側がテイクしたら防衛側の選択肢が大幅に減少する。最初に覗いてBサイト入口まで射線を通せると理想的。

### Bメイン
- **構造的特徴**: 初動の覗きはスキルマッチアップ次第。同等の実力なら攻撃側が勝てる構造。
- **オーブコントロール**: 両陣営とも難しい。スモークが返ってくると攻撃側が取れる可能性もある。
- **特徴**: サイトへの距離が近いため、そのままセットに移行しやすい。

## 攻撃側の強い動き

| 戦術名 | 概要 |
|---|---|
| **Aセット** | Aメインからスキルを合わせてサイト制圧 |
| **Aスプリット** | Aメイン＋ミッドからの挟み込み |
| **AフェイクB** | Aでフェイク後、Bへ展開 |
| **MIDフェイクB** | ミッドでフェイク後、Bへ転換 |
| **Bスプリット** | Bメイン＋エルボーからの挟み込み |
| **MIDデフォルト** | ミッドをコントロールしてデフォルト展開 |

---

## 防衛側の基本戦略

| 戦略名 | 概要 |
|---|---|
| **4-1配置** | 一人を固定してリテイク対応 |
| **オペレーター運用** | 長距離射線を活かしたピック |
| **マスキング** | 特定エリアを意図的に放棄し、リテイクに備える |
| **遠隔スキル返し** | [[Harbor]]・[[Sova]]・[[KAYO]]・[[Viper]] による遠距離からのスキル返し |
| **リテイク** | 中盤でのMID奪還から囲い込み |
| **ファストローテート＋カーテン分断** | カーテンでエリアを区切り、少人数で戦う |

---

## 推奨エージェント

- **[[Viper]]**: 長いカーテン（スクリーン）によるエリア分断が特に強力。遠隔スキル返しの要。
- **[[Harbor]]**: 曲がるカーテン（ハイタイド）を活用したエントリーサポートおよびスキル返し。
- **[[Sova]]**: 遠距離リコン・ドローンによる情報収集とエリア制圧。
- **[[KAYO]]**: ナイフによるスキル抑制と、フラッシュを起点とした強引なエリアテイク。
- **[[Jett]]**: アップドラフト＋ブリンクによる機動的なエントリー。オペレーター運用。
