# レイズ (Raze)

## 概要

グレネードとブームボットを利用した、エリア制圧能力に長けたデュエリストです。率先してスパイク設置エリアへ突入することを得意とします。

## 現在の評価

### 強み

- **立体的で素早い移動**: ブラストパックを駆使することで、空中を高速移動し、敵の意表を突くエントリーが可能です。
- **豊富なダメージアビリティ**: ペイント弾やショーストッパーなど、敵に直接ダメージを与えるアビリティが多く、キルを狙いやすいです。
- **狭所での圧倒的強さ**: 逃げ場が少ない狭い場所や通路において、範囲攻撃アビリティが極めて効果的に機能します。
- **索敵とゾーニング**: ブームボットによる安全なクリアリングや、グレネードによるエリア拒否が可能です。

### 弱み

- **操作の複雑さ**: ブラストパックを用いた移動には高度な技術と練習が必要です。
- **特定アビリティへのカウンター**: ブームボットなどの自律型アビリティは、スタンを受けると機能停止するため注意が必要です（※パッチ12.02で仕様変更）。
- **積極的な立ち回りの要求**: デュエリストとしての役割上、常に積極的なアクションが求められます。

## アビリティ

| アビリティ | 説明 |
|---|---|
| ブームボット | 索敵・追尾を行う自動走行ロボットを放つ |
| ブラストパック | 爆風で自身を飛ばしたり敵を弾いたりする（自傷ダメージなし） |
| ペイント弾 | クラスタ爆発するグレネード。1キルごとにリチャージ |
| ショーストッパー（ULT） | 超強力な範囲ダメージを与えるロケットランチャーを装備 |

## パッチ履歴

### パッチ 12.02
- **ブームボット**がスタン可能になりました。

## 推奨構成

- [[Bind]] や [[Lotus]]、[[Split]] などの狭いエリアや高低差が多いマップで優先的に採用。
- イニシエーターと連携してエリアを制圧する構成。
