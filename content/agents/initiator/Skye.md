# スカイ (Skye)

## 概要

追跡能力を持つ生物を召喚し、索敵とフラッシュ、回復を同時にこなす多才なイニシエーターです。敵の状況把握と味方の戦闘支援を得意とします。

## 現在の評価

### 強み

- **豊富な索敵手段**: トレイルブレイザーやガイディングライト、シーカーと、索敵できるアビリティが非常に多いです。
- **味方の回復能力**: 範囲内の味方のHPを回復でき、チームの生存能力を底上げできます。
- **汎用性の高いフラッシュ**: ガイディングライトは操作可能で、敵の位置を確認する索敵ツールとしても機能します。

### 弱み

- **操作の難易度**: 鳥（フラッシュ）や犬（スタン）の操作中に自身が動けず、かつ精緻な操作が要求されます。
- **使用中の無防備さ**: 回復中や操作アビリティの使用中は自身が攻撃できず、大きな隙を晒します。
- **特定アビリティへのカウンター**: シーカーなどの自律型アビリティは、スタンを受けると機能停止するため注意が必要です（※パッチ12.02で仕様変更）。

## アビリティ

| アビリティ | 説明 |
|---|---|
| リグロウス | 範囲内の味方を継続回復する。自身は回復不可 |
| トレイルブレイザー |  Tasmanian tigerを操作して索敵し、飛びかかって敵をスタンさせる |
| ガイディングライト | 鷹を操作して放ち、任意のタイミングで爆発させてフラッシュを焚く |
| シーカー（ULT） | 3体のシーカーを放ち、最も近い敵を追跡して視界を奪う |
