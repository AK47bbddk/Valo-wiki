# ゲッコー (Gekko)

## 概要

独自の生物たち（クリーチャー）を使役するイニシエーターです。スパイク操作の代行やスキルの再利用という唯一無二の特性を持ち、持続的なプレッシャーを与え続けます。

## 現在の評価

### 強み

- **スパイク操作の代行**: ウィングマンにより、自身が銃を構えたままスパイクの設置や解除を任せることができます。
- **アビリティの再利用**: ほとんどのアビリティ（モッシュピット以外）は、使用後に落ちた球体を回収することで再度使用可能です。
- **回避困難なフラッシュ**: ディジーは敵に青い液を浴びせて視界を完全に奪い、かつ位置を特定できる非常に強力な索敵・フラッシュツールです。

### 弱み

- **独特な使用感**: すべてのアビリティが生物を投げる動作を伴い、弾道や効果に癖があるため、習熟が必要です。
- **回収時のリスク**: スキルを再利用するためには、敵陣の近くまで球体を拾いに行く必要があり、隙を晒してしまいます。
- **特定アビリティへのカウンター**: ウィングマンなどの自律型アビリティは、スタンを受けると機能停止するため注意が必要です（※パッチ12.02で仕様変更）。

## アビリティ

| アビリティ | 説明 |
|---|---|
| ディジー | 空中に飛び出し、敵に視界を奪う液を吐き出す。回収可能 |
| ウィングマン | 敵を索敵し、最初に見つけた敵にスタンを与える。スパイクの設置/解除も可能。回収可能 |
| モッシュピット | 着弾地点に広がる毒液を投げる。一定時間後に中心部が大爆発する |
| スラッシュ（ULT） | 操作可能な生物になり、突進して敵を拘束（サプレッション状態）する。回収可能 |
