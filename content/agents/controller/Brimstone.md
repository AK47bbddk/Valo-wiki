# ブリムストーン (Brimstone)

## 概要

正確な空爆と即時展開可能なスモーク、バフアビリティを持ち、拠点の制圧と維持に優れたコントローラーです。敵の視界を塞ぎ、自由な行動を妨害することを得意とします。

## 現在の評価

### 強み

- **同時設置スモーク**: 最大3つのスモークを同時に、かつ瞬時に設置でき、サイト突入時の視界遮断能力に優れています。
- **強力なダメージアビリティ**: インセンディアリー（焼夷弾）により、設置阻止や敵の追い出しが可能です。
- **絶大な範囲攻撃**: アルティメット（オービタルストライク）は、特定のエリアを完全に焼き払い、スパイク解除阻止などに極めて有効です。

### 弱み

- **設置範囲の制限**: スモークを設置できる範囲（タブレットの射程）が狭く、自身の位置に依存します。
- **リソースの有限性**: スモークは使い切り（時間経過での回復なし）のため、使いどころを慎重に判断する必要があります。
- **アビリティ運用の難しさ**: 焼夷弾の空爆（定点）やアルティメットのタイミングなど、マップ知識と状況判断が求められます。

## アビリティ

| アビリティ | 説明 |
|---|---|
| スティムビーコン | 地面に設置し、範囲内の味方の連射速度と移動速度を上昇させる |
| インセンディアリー | 指定した地点に火炎を撒き散らす焼夷弾を放つ |
| スカイスモーク | タブレットで指定した地点に、長時間持続するスモークを降らせる |
| オービタルストライク（ULT） | 指定した広範囲を衛星軌道から攻撃し、甚大なダメージを与える |
