# ヴァイパー (Viper)
...
## 推奨される立ち回り

### ポストプラント（設置後）
- **空爆による解除阻止**: スネークバイト（毒液）を設置済みのスパイク（C4）周辺に散布することで、敵の解除を物理的に阻止し、時間を稼ぐことができます。

## アビリティ
...

化学物質を操り、視界遮断と強力なデバフで戦場を支配するコントローラーです。エリアの防衛と制圧において無類の強さを発揮します。

## 現在の評価

### 強み

- **広範囲の視界遮断**: トキシックスクリーンにより、非常に長い距離を一本のラインで遮ることができ、複数の射線を同時に切ることが可能です。
- **強力なデバフ（衰弱）**: すべてのアビリティが敵の最大HPを一時的に減少させる「衰弱」効果を持ち、敵の戦闘能力を著しく低下させます。
- **高い足止め能力**: スネークバイト（弱体化＋ダメージ）により、敵の進行を物理的に遅らせ、エリアを死守できます。
- **絶対的なエリア制圧**: アルティメット（ヴァイパーズピット）を展開したエリアは、敵にとって進入が極めて困難な死地となります。

### 弱み

- **利敵行為のリスク**: スモークが広範囲かつ永続的に残る（設置型）ため、展開タイミングを誤ると味方の邪魔をしてしまう可能性があります。
- **リソース管理の難しさ**: アビリティの使用には毒素（燃料）が必要で、ゲージが切れると一定時間アビリティを出せなくなります。
- **再設置の制限**: トキシックスクリーンやポイズンクラウドは一度設置すると再回収や再設置が難しい（またはできない）ため、最初の配置が重要です。

## アビリティ

| アビリティ | 説明 |
|---|---|
| ポイズンクラウド | 毒ガスを放出する小型装置を投げる。毒素を消費して起動 |
| トキシックスクリーン | 毒ガスを放出する長い装置を設置する。毒素を消費して起動 |
| スネークバイト | 弱体化（被ダメージ2倍）を与える化学物質を投げ、ダメージ床を作る |
| ヴァイパーズピット（ULT） | 自身の周囲に大規模な毒霧を展開し、敵を衰弱させ視界を極端に狭める |
