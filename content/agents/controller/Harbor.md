# ハーバー (Harbor)

## 概要

激流を操り、自在に曲がる水の壁を形成して進軍をサポートするアグレッシブなコントローラーです。イニシエーターのような妨害能力も兼ね備え、自ら撃ち合いの起点を作ることを得意とします（※パッチ 11.10 で大幅リワーク）。

## 現在の評価

### 強み

- **精密なスモーク設置**: コーヴ（固有アビリティ）が遠距離から精密に設置可能になり、シールドによる安全なエリア確保能力が向上しました。
- **強力な妨害手段**: 新アビリティ「ストームサージ」や、敵の足を止めるアルティメット（レコニング）により、攻め（エントリー）において圧倒的な存在感を発揮します。
- **自在に曲がるスクリーン**: ハイタイドにより、マップの構造に合わせた柔軟な視界遮断が可能です。

### 弱み

- **リソース管理の変化**: ハイタイドが有料スキルとなったため、以前よりも慎重なアビリティの使用が求められます。
- **防御（解除阻止）の難しさ**: 直接的なダメージアビリティは持たないため、依然として純粋な解除阻止は苦手です。

## アビリティ

| アビリティ      | 説明                                       |
| ---------- | ---------------------------------------- |
| ストームサージ    | 渦を発生させ、敵の視界を悪化させスロウ状態にする                 |
| コーヴ（E）     | 【固有アビリティ】シールド付きのスモークを遠距離から設置。銃弾を防ぐ       |
| ハイタイド      | 軌道を操作可能な長い水の壁を展開する（※パッチ 11.10 で有料化：300C） |
| レコニング（ULT） | 巨大な間欠泉を発生させ、当たった敵の視界を悪化させスロウ・スタンを与える     |

## パッチ履歴

### パッチ 11.10
- **大幅リワーク実施**
  - **コーヴ**: 固有アビリティー（E）に変更。設置精度向上（長押しで距離調整、視点切り替え可能）。
  - **ハイタイド**: 非固有アビリティーに変更。コスト 300C。
  - **ストームサージ**: 新アビリティ追加。
  - **レコニング**: 仕様変更（視界悪化とスロウの付与）。
  - 各種台詞の更新。
