# アストラ (Astra)

## 概要

アストラルフォームからマップ全域に「星」を配置し、吸引、スタン、スモークを自在に操る究極の戦術的コントローラーです。敵の視界を塞ぎ、自由な行動を妨害することを得意とします。

## 現在の評価

### 強み

- **全マップ対応の設置自由度**: アストラルフォームにより、自身の位置に関わらずマップのあらゆる場所に「星」を即座に配置し、アビリティを発動できます。
- **多彩な妨害能力**: 吸引（グラビティウェル）やスタン（ノヴァパルス）により、敵の進行阻止や設置/解除の妨害が極めて強力です。
- **「星」の回収によるフェイク**: 設置した星を回収する際、短時間のスモークを発生させることができ、これを利用したフェイクやローテーションが可能です。

### 弱み

- **使用中の無防備さ**: アストラルフォーム（操作画面）を開いている間は周囲の状況が全く分からず、自身が極めて無防備になります。
- **事前の設置が必要**: すべてのアビリティの発動には事前に「星」を設置しておく必要があり、咄嗟の対応には限界があります。
- **マルチタスクの難易度**: マップ全体の管理と味方の要望への対応、スキルのクールタイム管理など、非常に高度な状況判断と操作が求められ多忙です。

## アビリティ

| アビリティ | 説明 |
|---|---|
| アストラルフォーム | 宇宙視点でマップを見渡し、アビリティの起点となる「星」を配置する |
| グラビティウェル | 星を発動し、周囲の敵を中央に引き寄せ弱体化を与える |
| ノヴァパルス | 星を発動し、周囲の敵に強力なスタン（目眩）を与える |
| ネビュラ | 星を発動し、長時間持続するスモークを展開する |
| コズミックディバイド（ULT） | 巨大な壁を生成し、銃弾を遮断し音も完全にカットする |
