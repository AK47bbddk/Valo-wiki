# オーメン (Omen)

## 概要

テレポートと広範囲のスモーク、ブラインドを駆使し、影から敵を翻弄する機動力の高いコントローラーです。敵の視界を塞ぎ、自由な行動を妨害することを得意とします。

## 現在の評価

### 強み

- **スモーク設置の自由度**: ダークカヴァーを設置できる場所の自由度が高く、特殊なワンウェイスモークなども作りやすいです。
- **自由度の高いワープ**: シュラウドステップによる短距離ワープで、敵の意表を突くポジション取りや攪乱が可能です。
- **回避困難な視界奪取**: パラノイア（ブラインド）は効果範囲が広く、壁も貫通するため、敵にとって回避が非常に困難です。

### 弱み

- **スモーク設置の時間**: スモークの展開（アストラルのような操作）に時間がかかり、瞬時の対応が難しい場面があります。
- **アビリティ発動の遅さ**: ワープなどのアビリティ発動に隙があり、動作中に倒されるリスクがあります。
- **味方への誤爆リスク**: ブラインド（パラノイア）の効果範囲が広いため、味方の視界をも奪ってしまう可能性があります。

## アビリティ

| アビリティ | 説明 |
|---|---|
| シュラウドステップ | 短距離をテレポートする。音が発生するため注意が必要 |
| パラノイア | 壁を貫通し、触れた敵の視界と聴覚を奪う影を放つ |
| ダークカヴァー | 影の球体を設置し、長時間視界を遮る。飛距離や高さを自在に調整可能 |
| フロム・ザ・シャドウズ（ULT） | マップ上の任意の場所へテレポートする。索敵ツールとしても極めて優秀 |
