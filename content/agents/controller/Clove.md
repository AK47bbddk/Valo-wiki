# クローヴ (Clove)

## 概要

死を恐れずに戦う、アグレッシブなプレイスタイルが特徴のコントローラーです。デスした後も戦場に影響を与え続けることができ、チームを影（あるいは墓場）から支えます。

## 現在の評価

### 強み

- **前線を張れる性能**: コントローラーでありながら、キル後の回復（ピック・ミー・アップ）などを持ち、デュエリストのように果敢にエントリーや撃ち合いに参加できます。
- **デス後も使用可能なスモーク**: 倒された後も、自身の周囲（デス地点付近）にスモーク（ルース）を展開でき、チームへの貢献を継続できます。
- **強力な自己復活**: アルティメット（ノット・デッド・イェット）により、デスした瞬間にその場で復活し、戦闘を継続することが可能です。

### 弱み

- **フィジカルへの依存**: アビリティの性能を最大限引き出すにはキルが要求される場面が多く、プレイヤースキル（撃ち合いの強さ）が重要になります。
- **スモークの制約**: スモーク（ルース）の射程が他コントローラーに比べて狭く、かつ持続時間も短いため、精緻な管理が必要です。
- **復活のリスク**: アルティメットで復活しても、一定時間内にダメージを与えるかキルを取らなければ、再びデスしてしまいます。

## アビリティ

| アビリティ | 説明 |
|---|---|
| メドル | 敵の最大HPを一時的に減少させる衰弱の破片を投げる |
| ピック・ミー・アップ | 敵を倒すかアシストすると、自身のHPを一時的に回復し加速する |
| ルース | スモークを展開する。このアビリティはデスした後も使用可能 |
| ノット・デッド・イェット（ULT） | デスした直後に復活する。効果時間中にダメージ/キルで完全に蘇生 |
