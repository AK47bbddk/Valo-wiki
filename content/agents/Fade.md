# フェイド (Fade)

## 概要

恐怖を操り、敵の視界を奪い、聴覚を遮断して居場所を突き止める追跡型イニシエーターです。敵の位置把握とデバフによる妨害を得意とします。

## 現在の評価

### 強み

- **精緻な情報収集**: ホウントやプラウラーにより、敵の位置を把握し、かつ「恐怖の痕跡」で移動経路も追跡可能です。
- **豊富なデバフ効果**: 衰弱、聴覚遮断、拘束と、敵の戦闘能力を著しく低下させる手段が豊富です。
- **読みやすい敵の動き**: トレイル（痕跡）やプラウラーの追跡により、相手がどこに逃げようとしているかが可視化されます。

### 弱み

- **アビリティの対処しやすさ**: ホウント（目）は空中で破壊可能で、プラウラーも銃撃で壊されるため、使用タイミングに工夫が必要です。
- **地形への依存**: 一部のアビリティが段差や複雑な地形に弱く、効果が十分に発揮できない場合があります。
- **決定打の欠如**: 妨害能力は高いものの、単体で敵をキルしきったり、強引にエリアをこじ開けたりする力（自衛力・突破力）には欠ける面があります。

## アビリティ

| アビリティ | 説明 |
|---|---|
| プラウラー | 敵や痕跡を追跡する生物を放つ。当たった敵の視界を奪う |
| シーズ | 敵を地面に拘束し、衰弱と聴覚遮断を与える結界を投げる |
| ホウント | 視界内の敵をスキャンし、痕跡を付与する「目」を投げる |
| ナイトフォール（ULT） | 広範囲に悪夢の波動を放ち、敵を衰弱・聴覚遮断にし、痕跡を付ける |
