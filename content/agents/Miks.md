# ミクス (Miks)

## 概要

音波・振動系のアビリティを持つコントローラー。ハーモナイズ、ウェーブフォーム、M-パルス、ベースクエイクを駆使してエリアをコントロールする。

## 現在の評価

### 強み

- 多彩なアビリティによる複合的なエリア制御
- スモークと情報収集の両立

### 弱み

- パッチ12.06・12.08で複数のバグ修正があり、安定性は向上中

## アビリティ

| アビリティ | 説明 |
|---|---|
| ハーモナイズ | 視覚エフェクトで敵の視界を妨害 |
| ウェーブフォーム | スモーク展開アビリティ |
| M-パルス | 設置型センサー |
| ベースクエイク | 広範囲の振動アビリティ |

## パッチ履歴

### パッチ 12.06（2026/3/31）

- ハーモナイズで一人称視点のVFXが早く消える不具合を修正
- ハーモナイズの照準UIが味方ロードアウトと重なる不具合を修正
- ウェーブフォームのアビリティ設置UIがスモーク設置後も三人称視点で短時間表示される不具合を修正
- M-パルスがマップ上の特定地点に残って破壊できなくなる不具合を修正

### パッチ 12.08（2026/4/28）（12.07での修正・記載漏れ）

- ベースクエイク使用時にミニマップの円錐が点滅する不具合を修正
