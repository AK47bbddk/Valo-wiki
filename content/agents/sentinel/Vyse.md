# ヴァイス (Vyse)

## 概要

金属を操り、敵の視界や武器を封じ込めることで、戦闘を有利に進めるセンチネルです。重要なエリアの防衛、特に敵を分断して各個撃破することを得意とします。

## 現在の評価

### 強み

- **確実な分断能力**: シアー（壁）により、サイトに侵入した敵を後続から確実に切り離し、有利な撃ち合いを作り出すことができます。
- **強力なエリア拒否**: ラザーバイン（茨）は1歩ごとにダメージを与え、かつスロウ効果も高く、進行を強く抑制できます。
- **壁を貫通するフラッシュ**: アークローズは壁に設置し、反対側の敵にフラッシュを与えることができ、カウンターやエントリー支援に有効です。
- **武器の使用制限**: アルティメット（スティールガーデン）は広範囲の敵のメイン武器を一定時間使用不可にし、戦況を劇的に変えることができます。

### 弱み

- **デバイスの脆弱性**: アークローズやラザーバインなどのデバイスは銃撃で破壊されやすく、設置場所が露見すると対処されやすいです。
- **防衛エリアの限界**: 設置型アビリティの性質上、あまりに広いエリアの防衛や、複数の方向からの同時進行には対応しきれない場合があります。

## アビリティ

| アビリティ | 説明 |
|---|---|
| アークローズ | 壁に設置するフラッシュ。再使用可能 |
| シアー | 敵が通過すると起動する不可視の壁を設置。敵を分断する |
| ラザーバイン | 設置型トラップ。起動すると広範囲に茨を展開し、ダメージとスロウを与える |
| スティールガーデン（ULT） | 広範囲に金属の棘を放ち、敵のメイン武器を一定時間ジャム（使用不可）させる |
