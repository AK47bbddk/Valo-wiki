# ヴェト (Veto)

## 概要

エヴォリューション（変身系）能力を持つセンチネルです。敵のスキルを無効化したり、自身の形態を変化させたりすることで、エリアの防衛と制圧を同時にこなします。

## 現在の評価

### 強み

- **スキルの無効化**: 敵のスキルを無効化するアビリティを保持しており、相手のセットアップを根底から覆すことが可能です。
- **高い機動力と再ポジショニング**: テレポートが可能な設置型アビリティにより、センチネルでありながら素早い移動や位置変更が容易です。
- **究極の自己防衛**: アルティメットにより、自身に対するすべてのスキルを無効化でき、強制的にフィジカル勝負に持ち込めます。

### 弱み

- **攻撃時の難易度**: スキルの性質が防衛に特化しており、アタッカー側で有効に活用するには高度な判断が求められます。
- **破壊可能なデバイス**: すべてのアビリティがデバイスとして存在し、破壊されると完全に無力化されるため、配置が重要です。
- **事前の設置が必要**: すべてのアビリティをあらかじめ設置しておく必要があり、急な戦況の変化への対応力には欠ける面があります。

## アビリティ

| アビリティ | 説明 |
|---|---|
| クロスカット | 索敵・妨害アビリティ。[[スカーミッシュ_Ascension]] で使用可能 |
| チョークホールド | 壁越しの敵を感知・妨害する。パッチ12.08でバグ修正済み |
| エヴォリューション（ULT） | 変身して戦闘能力を強化し、自身へのスキル効果を無効化する |
