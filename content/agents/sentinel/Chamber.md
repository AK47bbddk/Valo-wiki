# チェンバー (Chamber)

## 概要

独自のカスタム武器とテレポートを使い、高い精度の射撃でエリアを制圧する攻撃的なセンチネルです。スパイク設置エリアの防衛を得意とし、個人技で戦局を有利に進めます。

## 現在の評価

### 強み

- **一撃必殺の個人アビリティ**: ヘッドハンター（ピストル）やツール・ド・フォース（スナイパー）により、経済状況に関わらず強力な火力を持てます。
- **瞬時の離脱能力**: ランデヴー（テレポート）により、強気なワンピックを狙った後に瞬時に安全圏へ離脱することが可能です。
- **自動索敵と遅延**: トレードマークにより、自身の見ていない経路の敵を検知し、スロウを付与して進行を遅らせることができます。

### 弱み

- **高い習熟度の要求**: アビリティのほとんどが射撃に依存しているため、プレイヤースキル（エイム）が直接釣果に直結し、安定させるのが難しいです。
- **事前の設置が必要**: テレポートなどのアビリティは事前にデバイスを設置しておく必要があり、柔軟な立ち回りには制限があります。
- **リソースの回復制限**: トレードマークなどの再設置クールタイムが長く、一度破壊されるとそのエリアの防衛力が著しく低下します。

## アビリティ

| アビリティ | 説明 |
|---|---|
| トレードマーク | 敵を検知し、スロウフィールドを発生させる罠を設置する |
| ヘッドハンター | 高精度のヘビーピストルを装備。ADS（照準）が可能 |
| ランデヴー | テレポートアンカーを設置。範囲内で再発動するとアンカー位置へワープ |
| ツール・ド・フォース（ULT） | 超強力な専用スナイパーライフルを装備。キルでスロウフィールド発生 |
