## 推奨される立ち回り

### 攻撃・防衛での活用
- **意表を突く壁設置**: バリアオーブ（壁）を意外な場所に設置し、高低差を利用して敵をキルする「キモオタ壁」のような運用も、1ピックを狙う上で有効です。

## アビリティ
...

回復と蘇生、そして強力な進路封鎖能力を併せ持つセンチネルです。スパイク設置エリアの防衛や、味方の生存率向上に特化した支援型エージェントです。

## 現在の評価

### 強み

- **唯一無二の回復・蘇生能力**: 味方のHPを回復（ヒーリングオーブ）させ、倒れた味方を戦線復帰（リザレクション）させることができ、人数不利を覆す力があります。
- **強力なエリア遅延**: スロウオーブやバリアオーブにより、敵の進行を物理的に、あるいは速度的に大幅に遅らせることが可能です。
- **場所に縛られない柔軟性**: 他のセンチネル（設置型デバイス持ち）に比べ、自身の立ち位置を柔軟に変えやすく、味方のサポートに回りやすいです。

### 弱み

- **時間の制約**: 回復には時間がかかり、蘇生（ULT）も発動から完全復帰まで大きな隙を晒すため、安全確保が必須です。
- **索敵能力の欠如**: 敵の情報を直接取得するアビリティを持たず、情報の収集は味方に依存します。
- **単一エリアへの防衛力**: 一度に防衛・封鎖できる場所が限定的であり、複数の方向からの同時進行には対処しにくい面があります。

## アビリティ

| アビリティ | 説明 |
|---|---|
| スロウオーブ | 地面に触れると爆発し、範囲内の敵の移動速度を下げ、足音を発生させる |
| ヒーリングオーブ | 味方または自身のHPを継続的に回復させる |
| バリアオーブ | 指定した場所に強固な壁を生成する。時間の経過や攻撃で破壊される |
| リザレクション（ULT） | 倒れた味方の遺体を選択し、フルHPで戦線に復帰させる |
