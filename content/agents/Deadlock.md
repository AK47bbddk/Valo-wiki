# デッドロック (Deadlock)

## 概要

ナノワイヤー技術を用いたバリアやトラップで敵を拘束し、進行を力ずくで止めるセンチネルです。重要なエリアの防衛、特に敵の突進を物理的に遮断することを得意とします。

## 現在の評価

### 強み

- **強固な進路封鎖**: バリアメッシュにより、敵の通行を物理的に遮断する壁を瞬時に生成でき、サイト突入を阻止する力が極めて高いです。
- **音に反応する索敵**: ソニックセンサーは範囲内の大きな音（足音、射撃、スキル使用）に反応してスタンを与えるため、アグレッシブなエントリーへのカウンターになります。
- **必殺のアルティメット**: アナイアレーションは最初に触れた敵を繭に閉じ込め、救出されなければ確定でキルを取ることができ、1対1の状況などで非常に強力です。

### 弱み

- **裏取り警戒の不安定さ**: センサーが音に依存するため、歩き進行（静かな移動）に対しては無力であり、純粋な裏取り警戒役としては不安が残ります。
- **攻撃時のアビリティ制限**: 設置型アビリティが多く、アタッカーとしてサイトを攻める際に活かせるアビリティが限られます。
- **再設置の不可**: センサーなどのアビリティは一度設置すると回収して再利用することができないため、配置ミスが致命的になります。

## アビリティ

| アビリティ | 説明 |
|---|---|
| グラブネット | 範囲内の敵をしゃがみ状態に強制し、移動速度を大幅に下げる手榴弾を投げる |
| ソニックセンサー | 壁に設置。音を検知すると範囲内にスタン（目眩）を発生させる |
| バリアメッシュ | X字型の物理的なバリアを展開し、キャラの通行を遮断する。弾丸は貫通する |
| アナイアレーション（ULT） | ナノワイヤーのパルスを放ち、触れた敵を捕獲。時間内に救出されなければキル |
