# ソーヴァ (Sova)

## 概要

リコンボルトやドローンを駆使し、遠距離から精緻な情報を収集することに長けたイニシエーターです。敵の状況把握を得意とします。

## 現在の評価

### 強み

- **正確な情報収集**: リコンボルトやオウルドローンにより、敵の位置を正確にピンポイントで把握できます。
- **広範囲の索敵**: スキルの射程が長く、一度に広範囲の状況を確認することが可能です。
- **高い奇襲性と可能性**: 矢（ボルト）を壁に反射させることで、予測不能な位置からの索敵やダメージ（定点）が可能です。

### 弱み

- **操作の難易度**: 矢の弾道計算やドローンの操作など、習熟が必要な技術が多いです。
- **使用中の無防備さ**: ドローン操作中などは自身が完全に無防備になり、周囲の安全確保が必要です。
- **知識への依存**: 各マップの定点知識がないと動きがワンパターンになりやすく、敵に対処されやすくなります。

## アビリティ

| アビリティ | 説明 |
|---|---|
| オウルドローン | 操作可能なドローンを放ち、ダートを撃ち込んで敵の位置を公開する |
| ショックボルト | 着弾時に爆発する矢を放つ。最大2回反射させることが可能 |
| リコンボルト | 範囲内の敵をスキャンする矢を放つ。最大2回反射可能 |
| ハンターズフューリー（ULT） | 壁を貫通する長射程の衝撃波を最大3回放つ。当たった敵をハイライト |
