# ハーバー (Harbor)

## 概要

激流を操り、自在に曲がる水の壁を形成して進軍をサポートする攻撃的なコントローラーです。敵の視界を塞ぎ、味方のエントリーを強力に後押しすることを得意とします。

## 現在の評価

### 強み

- **自在に曲がるスクリーン**: ハイタイドにより、広範囲の視界を複雑な形状で遮ることができ、マップの構造に合わせた柔軟なライン形成が可能です。
- **強力なエントリー支援**: 前進する壁（カスケード）や、敵の足を止めるアルティメット（レコニング）により、攻め（エントリー）において真価を発揮します。
- **防弾スモーク**: コーヴは短時間ながら銃弾を防ぐシールド付きのスモークを展開でき、安全な設置や解除を可能にします。

### 弱み

- **設置難易度の高さ**: スクリーンの操作やアビリティのタイミングが難しく、配置を誤ると味方の射線を遮る「利敵行為」になりやすいです。
- **防御（解除阻止）の弱さ**: すべてのアビリティが視界遮断系であり、ダメージアビリティを持たないため、設置後の解除阻止（空爆等）が苦手です。
- **ピーキーな性能**: 突破力に特化した尖った性能をしており、状況判断が難しく上級者向けのエージェントです。

## アビリティ

| アビリティ | 説明 |
|---|---|
| カスケード | 前進する水の壁を放つ。壁を通り抜けた敵にはスロウを与える |
| コーヴ | 銃弾を防ぐシールドを展開する水球を投げる。耐久値を超えると破壊される |
| ハイタイド | 軌道を操作可能な長い水の壁を展開する。触れた敵にスロウを与える |
| レコニング（ULT） | 巨大な間欠泉を発生させる陣を展開。範囲内の敵を追尾し、連続でスタンさせる |
