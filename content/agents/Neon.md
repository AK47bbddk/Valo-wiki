# ネオン (Neon)

## 概要

圧倒的な機動力と高いタンク性能、そして強力なキルプレッシャーを併せ持つ電気系デュエリストです。率先してスパイク設置エリアへ突入することを得意とします。

## 現在の評価

### 強み

- **圧倒的な移動速度**: ハイギアによる疾走で素早いエリア確保やローテーションが可能です。
- **使いやすいスタン**: リレーボルトはクイックキャストで放て、エントリー時の敵の無力化に非常に効果的です。
- **近距離戦の優位性**: スピードとスライディングを活かした近接戦闘、特にショットガン（[[ジャッジ]]等）とのシナジーは絶大です。
- **視界遮断とライン形成**: ファストレーン（カーテン）により、安全な進路確保と敵の射線制限が可能です。

### 弱み

- **高度な操作とエイム**: 高速移動中のエイム制御やキャラコンには、非常に高いプレイヤースキルが要求されます。
- **味方への妨害リスク**: スタンやカーテンの壁が味方の視界や動きを制限してしまう可能性があります。
- **積極的な立ち回りの要求**: デュエリストとしての役割上、常にリスクを伴うアクションが求められます。
- **パッチ 12.09 での弱体化**: 高速移動の制限（バニーホップ制限）やキル時の燃料回復削除により、リソース管理がより厳格になりました。

## アビリティ

| アビリティ | 説明 |
|---|---|
| ハイギア | 疾走状態。スライディングが可能。パッチ12.09で弱体化 |
| リレーボルト | 跳ね返るエネルギー弾を放ち、2箇所でスタンを発生させる |
| ファストレーン | 視界を遮り、ダメージを与える2枚のエネルギーの壁を作る |
| オーバードライブ（ULT） | 指先から電撃を放つ。キルで効果時間とスライディングが回復 |

## パッチ履歴

### パッチ 12.09（2026/05/08）
- **ハイギア (E) の弱体化**: バニーホップによる高速移動を制限。
- **燃料回復の削除**: キル獲得時のハイギアエネルギー回復を削除。
- **ショットガン下方修正**: 機動力と組み合わせた戦法への間接的な弱体化。
