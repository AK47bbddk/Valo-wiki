# フェニックス (Phoenix)

## 概要

避けづらいフラッシュ、自己修復可能なスキル、そして回転率の高いアルティメット（ULT）を武器にするデュエリストです。アビリティの使いどころが分かりやすく、初心者から上級者まで幅広く扱えます。

## 現在の評価

### 強み

- **アビリティの分かりやすさ**: 攻守において使いどころが明確で、状況判断がしやすいです。
- **高い自己完結能力**: スキル（ホットハンズ、ブレイズ）で自身のHPを回復できるため、連戦や単独行動に強いです。
- **射線制限とエリアテイク**: 火の壁（ブレイズ）による射線制限と、避けづらいフラッシュ（カーブボール）によるエントリーが強力です。
- **高回転のアルティメット**: 必要ポイントが低く、積極的にオーブを回収することで頻繁に発動し、リスクなしでエントリーや索敵が可能です。

### 弱み

- **味方への誤爆リスク**: アビリティ（フラッシュ、火炎、壁）が味方にも当たってしまうため、連携には注意が必要です。
- **回復と攻撃のトレードオフ**: 回復のためにスキルを使用すると、その後の攻める手段を失ってしまいます。
- **集団行動の難しさ**: アビリティの性質上、仲間と密集して行動するのには不向きな場面があります。

## アビリティ

| アビリティ | 説明 |
|---|---|
| ブレイズ | 視界を遮りダメージを与える火の壁を作る。自身を回復可能 |
| カーブボール | 左右に曲がるフラッシュを放つ。視認後の回避が困難 |
| ホットハンズ | 火炎瓶を投げ、敵にダメージを与え自身を回復する |
| ラン・イット・バック（ULT） | 一定時間、倒されても発動地点で復活する。HPも全回復 |
