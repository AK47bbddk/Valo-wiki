# ジェット (Jett)

## 概要

唯一無二の機動力とスモークを兼ね備え、VALORANTのデュエリストの中でもトップクラスのエントリー能力を誇るエージェントです。率先してスパイク設置エリアへ突入することを得意とします。

## 現在の評価

### 強み

- **唯一無二の機動力**: 縦横に素早く移動ができ、縦方向の移動（アップドラフト）と横方向の移動（テイルウィンド）を使い分けることが可能です。
- **生存能力を補助するスモーク**: 即展開可能なスモーク（クラウドバースト）により、エントリー時の安全確保や緊急時の射線遮断が可能です。
- **パッシブによる滞空能力**: ドリフトにより長時間の滞空が可能で、通常では不可能な射線やポジション取りができます。
- **強力なエントリー能力**: チョークポイントを抜ける際、ブリンクとスモークを組み合わせることで敵の視点を揺さぶります。
- **理不尽なワンピック**: オペレーターを持ち、キル直後に離脱する動きは極めて強力です。

### 弱み

- **操作の複雑さ**: エージェントの操作難易度が高く、習熟が必要です。
- **直接的な戦闘補助の少なさ**: 撃ち合い自体（エイム等）を補助するアビリティが少なく、フィジカルが要求されます。
- **積極的な立ち回りの要求**: デュエリストとしての役割上、常に積極的なアクションが求められます。

## アビリティ

| アビリティ | 説明 |
|---|---|
| ドリフト（パッシブ） | 空中でジャンプボタンを押し続けることで落下速度を遅くする |
| クラウドバースト | 即展開の視界遮断スモーク（投擲方向を操作可能） |
| アップドラフト | 上空へ飛び上がる |
| テイルウィンド | 瞬間ダッシュ。準備動作が必要。キルで再チャージ |
| ブレードストーム（ULT） | 高精度の投擲ナイフ。キルで全弾回復 |

## 推奨構成
- [[Ascent]] 等、エリア取りが重要なマップで真価を発揮。
- オペレーターを主軸に置く構成で必須級。
- 高低差の激しいマップ（Icebox等）で有利に立ち回れる。
