# エージェント考察：フェニックス (Phoenix)

フェニックスは、避けづらいフラッシュや自己修復可能なモロトフ、回転率の高いアルティメット（ULT）を武器に、現環境で特定の役割を担うエージェントとして再評価されています。

## 1. 採用の背景と傾向

- **Yoruの代替枠**: 避けづらいフラッシュや、低ポイントで使用可能なULTの強みを活かし、弱体化したYoruの枠に代わる選択肢として出現しました。
    
- **過去の運用**: 以前はPRXのJinggg選手などがパールで採用していたことで知られています。
    
- **現在の採用マップ**: 現行のマッププールでは、ヘイブン、パール、フラクチャーなどでその姿が見られます[cite: 5, 8, 9]。
    

## 2. 防衛側での立ち回り

- **エリアテイク**: セットアップされたモロトフとフラッシュを組み合わせた、強気なエリア奪還が強力です[cite: 5, 9]。
    
- **中盤の情報収集**: フラッシュを単体で流すことで、敵の配置や進行の情報を安全に確認できます[cite: 5]。
    
- **セットプレイへのカウンター**: 敵のサイトエントリーに対し、自身のカーテン（ブレイズ）で射線を切りつつサイト内へ入り、フラッシュでエントリーキャラを無力化する動きが有効です[cite: 5, 9]。
    

## 3. 攻撃側での立ち回り

- **オーブ回収とULT運用**: 積極的にアルティメットオーブを回収し、回転率の良いULTを早期に溜める展開が基本です[cite: 5, 9]。
    
- **役割の柔軟性**: 本陣に随伴してサイトを制圧するだけでなく、単独で敵のガジェット破壊や情報の撹乱を行う動きも可能です[cite: 5, 9]。
    
- **ULTによる主導権確保**: 強力なセットアップが複数存在し、ULT（ラン・イット・バック）を投資することでラウンドの主導権を確実に握ることができます[cite: 5, 9]。
    

## 4. 撃ち合いの駆け引き

- **ドライ進行の重要性**: 強力なフラッシュを所持しているからこそ、あえてスキルを使わない「ドライ進行」を混ぜることが重要です。
    
- **戦術のじゃんけん**: 相手との「じゃんけん構造（攻防の相性）」を理解し、読み合いを制することがフェニックス使いには求められます。
