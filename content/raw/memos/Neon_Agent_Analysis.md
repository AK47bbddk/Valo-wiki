# エージェント考察：ネオン (Neon)

ネオンは、圧倒的な機動力と高いタンク性能、そして強力なキルプレッシャーを併せ持つデュエリストであり、現環境のメタにおいても重要な役割を果たしています。 [cite: 7, 8, 10]

## 1. エージェントの強み
- **高いキルプレッシャーとタンク性能**: 強力なスライディングによる撃ち合いの優位性に加え、パッシブの移動速度とカーテン（ファストレーン）による高いタンク性能を誇ります。 [cite: 6, 10]
- **サステイン（維持力）**: スライディングがチャージされていない状態でも、高い機動力を活かしたエントリーが可能です。 [cite: 6]
- **広範囲の妨害スキル**: クイックキャストで放たれる広範囲のスタン（リレーボルト）は、エリア制圧や敵の無力化に非常に強力です。 [cite: 6, 8]
- **カーテンエントリー**: カーテンを利用したエントリーは生存率が高く、ミニマップで敵の位置をわずかに捉えるだけでも、スタンとスライディングを組み合わせて強引にキルを狙うことができます。 [cite: 6, 9]

## 2. 特殊な運用とプレイスタイル
- **キャラコンとショットガンのシナジー**: 高度なキャラコンとジャッジ（ショットガン）を組み合わせた運用は、近距離戦闘において絶大な威力を発揮します。 [cite: 7, 8, 10]
- **著名なプレイヤー**: じぇじぇぽっぽやDambiなどの高いキャラコン技術を持つ選手や、Aspas、Meiyといったトッププレイヤーも大会でこのエージェントを使いこなしています。 [cite: 6]
- **後続への貢献**: 自らがキルを取るだけでなく、敵のヘイトを引くことで後続の味方にキルやトレードを取らせる動きも優秀です。 [cite: 6]

## 3. 弱点と構成の変遷
- **弱点**: 性能の高さゆえ、楽しくてついついアグレッシブに突っ込みすぎてしまう点に注意が必要です。
- **構成の変遷**: 
  - かつてはYoruやWely（Vyse）と組み合わせた「ダイブ構成」が強力でしたが、パッチによるナーフ（弱体化）の影響もあり、現在は以前ほどは見かけなくなっています。 [cite: 8, 10]
  - **フェニックスとの相性**: 現環境ではフェニックスとのダブルデュエリスト構成が評価されており、実戦でもその組み合わせが確認されています。 [cite: 7, 9]

## 4. ナーフの影響
- パッチにより、スライディングやジャンプ時の精度が低下するなど、プロレベルでも運用方法が試行錯誤されていますが、依然としてエントリーやエリアコントロールにおけるスピードは戦術の基盤となっています。 [cite: 9, 10]
